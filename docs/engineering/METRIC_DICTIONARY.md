# 指标字典
| 指标 | 单位 | 口径 |
|---|---|---|
| CPU | % | 进程 CPU，注明单核/多核归一化 |
| RSS | bytes | 进程驻留内存 |
| Goroutine | count | 运行时采样数 |
| GC pause | ms | 暂停分布与采样窗口 |
| Heap | bytes | 活跃堆或分配总量需明确区分 |
| 函数耗时 | ns/op | Go benchmark |
| 分配 | B/op、allocs/op | Go benchmark |
| 行情吞吐 | msg/s | 指定处理边界与负载 |
| 行情延迟 | ms | 接收至状态更新，明确起止 |
| 陈旧时间 | ms | 事件时间至观察时刻，注明时钟误差 |
| 策略延迟 | μs/ms | 输入准备至决策，另列纯计算 |
| 模拟执行延迟 | ms | 决策至模拟执行结果 |
| 锁等待 | μs/ms | 明确 profile 采样与聚合 |
| 重连恢复 | ms/s | 断线至有效行情恢复 |
| 消息丢失率 | % | 可验证缺失消息/预期消息；分母明确 |
延迟类报告 P50/P95/P99 与样本数。当前全部实测指标 UNAVAILABLE。
