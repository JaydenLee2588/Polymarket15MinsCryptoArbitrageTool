# Benchmark 规范
先静态分析提出假设，再动态测量建立基线；每次只改变一个主要变量，功能及性能回归同时通过后才可接受。记录 commit、工具链、OS、CPU、内存、GOMAXPROCS、配置、输入数据版本、负载、预热、重复次数、命令、原始结果及统计方法。区分冷启动与稳定运行、离线与网络测量。采样、基线和对照条件一致；重复测量，报告波动与不确定性。Go microbenchmark 使用 testing.B 与 -benchmem；比较工具及版本需记录。延迟需给出样本量及 P50/P95/P99，不能只报告均值。未测量标 UNAVAILABLE；不得编造数据。实验报告包含假设、变更、结果、回归、局限、结论、回滚条件。
