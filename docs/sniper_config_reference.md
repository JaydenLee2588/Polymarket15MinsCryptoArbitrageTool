# Sniper-C "死鱼策略" 配置字段详解

以下是 `strategy_config_3.yaml` 中 **Sniper-C** 策略各配置字段的详细中文解释。

## 1. 基础配置 (Group Level)

| 字段 | 值 | 解释 |
| :--- | :--- | :--- |
| **id** | `"Sniper-C-死鱼"` | **策略唯一标识符**。用于日志区分和数据库记录。 |
| **trend_window_sec_start** | `150` | **开始监控时间** (秒)。开盘后 150 秒（即 2分30秒）才开始运行。跳过前期的剧烈波动，专注于后半段。 |
| **trend_window_sec_end** | `900` | **结束监控时间** (秒)。开盘后 900 秒（即 15分钟）结束。覆盖到市场结算那一刻。 |
| **leg0_share_price_0** ~ **leg1_share_price_3** | (0.01 - 0.99) | **价格档位**。在 Sniper 纯狙击模式下，主要起占位作用。Sniper 使用自己的逻辑判断买入，但资金管理模块可能会参考这些值。设置为 0.99 意味着“即使很贵也允许买”。 |
| **leg1_share_amount_1** ~ **leg1_share_amount_3** | `10` | **买入数量**。每次触发 Sniper 信号时买入的合约数量。这里设置为 10，属于较大额度，旨在捡漏（因为机会少，一旦有就要重拳出击）。 |
| **max_slippage** | `0.05` | **最大允许滑点**。下单时允许成交价偏离当前最优价的幅度 (5%)。 |
| **patterns** | `[]` | **形态列表**。为空表示不使用传统的 K线形态（如“火箭发射”），完全依赖 Sniper 逻辑。 |
| **sell_threshold** | `0.05` | **保底止盈阈值**。如果 Sniper 自身的逻辑没触发卖出，当盈利达到 5% 时也会强制止盈。 |
| **enable_stop_loss** | `false` | **时间止损开关**。关闭。死鱼策略通常是持有到归零或翻倍，或者因极短时间内回归而止盈，不需要传统的时间止损。 |
| **stop_loss_minutes_before_close** | `0` | **结算前止损**。设置为 0，意味着一直持有到最后结算（如果需要）。 |

## 2. Sniper 特有配置 (Sniper Config)

| 字段 | 值 | 解释 |
| :--- | :--- | :--- |
| **zscore_entry_threshold** | `3.0` | **Z-Score 入场门槛**。在 Phase 4 (最后30秒)，死鱼策略**不依赖 Z-Score** 入场，主要依赖概率错配。所以这个值在这里设得很高（3.0），基本上只起参考作用。 |
| **zscore_exit_threshold** | `0.0` | **Z-Score 退出门槛**。设置为 `0.0` 意味着**禁用 Z-Score 回归止盈**。死鱼策略是基于“必胜/必败”概率的，不关心 Z-Score 是否回归到 0。之前这里通过代码修复了 0.0 被忽略的问题。 |
| **profit_exit_pct** | `2.0` | **盈利退出百分比**。只要盈利达到 2% 就立即跑路。死鱼策略是“捡分分钱”，积少成多，不贪大。 |
| **spread_max** | `0.05` | **最大盘口价差**。如果 Poly 市场上 Bid/Ask 差价超过 $0.05，认为流动性太差，不交易。 |
| **dead_fish_min_edge** | `0.01` | **死鱼最小优势 (Edge)**。核心参数。只要【理论价值 - 市场价格 > $0.01】就触发。例如理论值 $0.00，市场卖 $0.02，Edge=-0.02 (不买)。如果市场卖 $0.005，Edge=0.005 (不买)。如果理论值 $1.00，市场卖 $0.98，Edge=0.02 (>0.01)，**买入！** |
| **edge_threshold** | `0.05` | **常规优势阈值**。在 Phase 3 (30秒~3分钟) 时使用的优势门槛。比死鱼阶段要求更高（5%），因为此时还有时间变数。 |

## 3. 策略逻辑总结

**Sniper-C** 的核心思想是：
> 在比赛快结束（或已经结束但市场未结算）时，寻找那些**定价错误**的合约。
> 例如：比赛确实已经结束了，结果是 A 赢。理论上 A 的价格应该是 $1.00。但市场上可能还有人挂在 $0.97 卖。
> 这时候 Sniper-C 发现 Edge = $0.03 > $0.01，就会果断吃进这 10 个币，几秒钟后结算赚取无风险的 $0.30。
